# Public Pages

| URL | Page / Purpose |
|---|---|
| `/` | Main landing page — premium introduction, featured work, highlights, and navigation to major sections. |
| `/blogs` | All blogs and articles — searchable/filterable list of published content. |
| `/blogs/by/[author]` | Blogs written by a specific author, e.g. `/blogs/by/anuj`. |
| `/blogs/by/[author]/[slug]` | Individual blog/article page, e.g. `/blogs/by/anuj/my-first-article`. |
| `/about` | About overview — introduction and gateway to different profile sections. |
| `/about/[section]` | Dynamic individual About section pages, such as `/about/anuj`, `/about/skills`, or `/about/timeline`. |
| `/about/anuj` | Detailed personal/professional introduction. |
| `/about/skills` | Skills overview and technology expertise. |
| `/about/timeline` | Professional and personal journey timeline. |
| `/skills` | Dedicated full skills page with categories, technologies, and expertise. |
| `/my-timeline` | Dedicated interactive career and journey timeline. |
| `/certificates-achievements` | Certificates, awards, achievements, competitions, and recognitions. |
| `/works` | All projects and work — portfolio listing with filtering and categories. |
| `/works/by/[author]` | Work/projects by a specific author, e.g. `/works/by/anuj`. |
| `/works/by/[author]/[slug]` | Individual project or detailed project case study. |
| `/resume` | Online resume with option to view or download the latest active resume. |
| `/contact` | Contact information, social links, and contact form. |

# Admin Area

| URL | Page / Purpose |
|---|---|
| `/admin` | Admin dashboard — overview, statistics, recent activity, and quick actions. |
| `/admin/login` | Secure admin authentication. |
| `/admin/profile` | Manage portfolio profile and personal information. |
| `/admin/blogs` | Manage all blogs and articles. |
| `/admin/blogs/new` | Create a new blog/article. |
| `/admin/blogs/[id]` | Edit, preview, publish, or manage an individual blog. |
| `/admin/works` | Manage all projects and portfolio work. |
| `/admin/works/new` | Create a new project/work. |
| `/admin/works/[id]` | Edit and manage an individual project. |
| `/admin/about` | Manage About page sections and their ordering. |
| `/admin/about/[id]` | Edit an individual dynamic About section. |
| `/admin/skills` | Manage skills, categories, technologies, and related metadata. |
| `/admin/timeline` | Manage timeline events and their ordering. |
| `/admin/experience` | Manage professional experience. |
| `/admin/education` | Manage education information. |
| `/admin/certificates` | Manage certificates and credential links. |
| `/admin/achievements` | Manage awards, competitions, and achievements. |
| `/admin/resume` | Upload, replace, and select the active public resume. |
| `/admin/media` | Central media library for images, PDFs, and other uploaded files. |
| `/admin/contact` | View and manage contact form submissions. |
| `/admin/authors` | Manage author information if multi-author support is enabled. |
| `/admin/tags` | Manage content tags and categories. |
| `/admin/homepage` | Control homepage featured content, sections, and ordering. |
| `/admin/seo` | Manage global SEO and default metadata. |
| `/admin/settings` | General portfolio, social, API, and application settings. |
